# Azure VM Web Hosting Project

## Objective

Deploy a website on an Ubuntu Virtual Machine in Microsoft Azure and make it accessible via a public IP address.

## Azure Services Used

- Azure Virtual Machine
- Virtual Network
- Network Security Group
- Public IP Address
- Nginx

  ## Architecture

Internet
|
Public IP
|
NSG
|
Ubuntu VM
|
Nginx

## Tasks Completed

1. Created Resource Group
2. Created Virtual Network
3. Deployed Ubuntu VM
4. Connected using SSH
5. Installed Nginx
6. Opened Port 80
7. Hosted Website
8. Tested Website Accessibility

## Lessons Learned

- How Azure networking works
- How NSGs control traffic
- How Public IPs expose services
- How to host websites using Nginx
